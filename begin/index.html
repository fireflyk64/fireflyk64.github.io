BEGIN — A Tactical Starship Simulation

Begin 2.00 (c) 1984-1991 Clockwork Software — Rust port, in your browser.
advanced
Multiplayer: a console player hosts with begin host and reads you the room code — the simulation runs on their machine and this page is your bridge console. Single player runs the identical Rust engine compiled to WebAssembly, right here.

Commands: help lists them. helm 135 6, lock all banks on kronos, fire all banks 45, load all tubes, fire all tubes, scan kronos, damage, an empty line lets a cycle pass, quit ends the simulation.
